## 🚀 Featured Projects

### 🚖 UCAB – Online Cab Booking System
MERN-stack cab booking web app with role-based access for riders, drivers, and admins, authenticated via JWT and email OTP.
- Real-time request booking & live tracking using **Socket.IO** and **Google Maps API**
- REST APIs over an 11-collection **MongoDB** schema with distance-based fare calculation and surge pricing
- Responsive React.js + Tailwind CSS UI for bookings, payments, tracking, and ride history
- Admin approval flows for driver documentation, discount coupons, and ratings

**Tech Stack:** React.js, Node.js, Express.js, MongoDB, Socket.io, JWT, Tailwind CSS, Google Maps API

### 🤖 AI Chatbot Assistant
ChatGPT-style AI assistant that streams responses token-by-token via **SSE**, built on FastAPI and the OpenAI API.
- JWT authentication with bcrypt password hashing; all queries scoped per logged-in user
- REST APIs for creating, renaming, pinning, deleting, and searching chats with multi-level conversation history in MongoDB
- Optimized response latency via concurrent DB queries, limited context size, and background writes
- Responsive React.js UI with Markdown parser, code highlighter, theme toggler; containerized with Docker Compose
